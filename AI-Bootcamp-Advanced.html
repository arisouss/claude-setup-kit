What a skill is

You explain the same job every week. You can stop.
1 min

You said all that last week.
Every Monday you explain the same job to Claude, from the start. There is a way to explain it once.
The idea
A skill is
a job you explain once.
A skill is a saved routine. You explain a job once. After that you ask for it by name.
What is inside
quick-brief/
SKILL.md the steps, in plain words
references/ files the job needs
A skill is just a folder. Inside is a plain text note with the steps, and any files the job needs.
How it works
You askquick brief this
→
Claude spots the matchby name and one line
→
It opens the skilland follows the steps
Claude keeps only the name and one line about each skill in mind. It opens the full steps when a job needs them.
Why it matters
1Same result every timeThe steps do not change.
2Short promptsThree words, not thirty lines.
3Easy to shareYou can give it to other people.
The job is done the same way every time, without a long prompt.
Your rule
1Done it onceJust write a prompt.
2Done it three timesMake it a skill.
Not every job needs a skill. Make one when you have done the same job three times.

Skills from the internet

You are about to install a stranger's instructions.
1 min
Start here
A skill is a set of instructions
that Claude will follow.
You find a great-looking skill online. One click and it is installed. Stop for a moment.
The problem
1Read your filesAnd pass them on.
2Run a programSome skills carry scripts.
3Change how Claude actsWithout telling you.
A bad skill can tell Claude to do things you never asked for, with your files and in your name.
Good news
You can read every line
before you install it.
A skill is plain text. You can open it and read it before you install it. So can Claude.
The 5 point check
1Who made it?A name you can find and trust.
2Can you read it?Open SKILL.md. It should make sense.
3Any programs?Files ending in .py, .sh, .js or .exe need a second look.
4Any web addresses?Why would it send anything anywhere?
Five questions, two minutes.
The safe test
Empty test folder
→
Manual modeit asks before each action
→
Watch what it doesstop if it surprises you
Still unsure? Try it once on Manual, in an empty folder, with nothing confidential in it.
Your rule
1From the Claude directoryFine.
2From someone you trustFine.
3From anywhere elseCheck it first, or ask.
Anthropic's advice: stick to skills from the Claude directory. For anything else, check first or ask.

What an agent is

What if Claude did the job without being asked each time?
1 min
Start here
Same job. Every Monday.
By hand.
Every Monday you sort the same folder and write the same summary. By hand.
The idea
1A goalWhat done looks like.
2ToolsYour folder, the web, a skill.
3RulesWhat it may and may not do.
4Stop pointsWhere it must ask you.
An agent is Claude with a goal, tools, and permission to take the steps itself.
You already use one
You have been using
an agent all along.
When Claude opens your files and builds a deck step by step, it is acting as an agent.
Helpers
One big job
→
Claude splits itamong helpers
→
One resultback to you
For a big job Claude can split the work among helpers that run side by side. That is faster, and it uses more of your limit.
Why it matters

Let it run

Read and summarize

Sort and rename

Write a draft

Always ask me

Send or post anything

Delete anything

Spend money or sign up

The more Claude does on its own, the more the rules matter. Reading is low risk. Sending, deleting and paying need you.
Your rule
1Start smallA job where a mistake costs nothing.
2Read every resultAt first, every time.
3Then widenOnly when it has earned it.
You stay responsible for what Claude does in your name. Give an agent a small job first.

Build your first agent

Ten minutes. A small job that runs without you.
1 min
Start here
An agent is
a brief that repeats.
You will not build a robot. You will write a clear brief and let Claude repeat it.
Step 1
1Do it onceWith Claude, in a normal chat.
2Fix itUntil you are happy with the result.
Do the job once by hand, with Claude, until the result is right.
Step 2
Goal: a summary of my inbox folder
Use: the files in 00_Inbox
Steps: read, group, summarize
Never: delete, send, rename
Stop and ask: if a file looks confidential
Result: one page in 01_Projects
Write the agent's brief. Six lines are enough.
Step 3
The brief
→
/scheduleor Scheduled in the menu
→
Pick a timeevery Monday at 9
Ask Claude to make it repeat. Type /schedule, or open Scheduled in the left menu.
Good to know
1Uses your folderThe app must be open.
2Laptop asleepIt runs when you are back.
A job that uses your folder needs the Claude app open. If your laptop is asleep, it runs when you come back.
Step 4
1Read every runAt first.
2Adjust the briefWhen something is off.
3Pause or deleteWhen the job is over.
Read the result after every run for the first weeks. Pause the agent when you no longer need it.

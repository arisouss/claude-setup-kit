How it works

2Every file it readsEach page. Each picture.

- Date: 12 March

A .md file is plain text with a few simple marks. A hash makes a title. A dash makes a list.
Why Claude likes it

A PDF or Word file

Words plus layout and fonts.

Claude also gets every page as a picture.

Costs many tokens.

A .md file

Only the words.

Nothing hidden.

Costs few tokens.

A PDF carries layout, fonts and a picture of every page. A .md file carries only the words.
Why you will like it
Claude reads it easily.
So can you.
That is why Claude's notes about you are .md files. Open one. You can read every word, and fix it.

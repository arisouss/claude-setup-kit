The Claude setup kit · level 3

Claude Code: one folder, three words.

Claude Code is the Code tab inside the Claude app. It reads its rules from your folder by itself, so the setup is shorter: download a folder, open it, and say "Set me up."

claude-code-starter.zipA ready folder: the rule book, four skills and two helper agents.
Download

Stay with the normal Claude chat if

You want the simplest path, you work mostly with documents and decks, and one thing at a time is enough.

Move to Claude Code if

You want Claude to remember its rules without being told, run several jobs at once, and hand work to helper agents.

Set it up in 5 minutes

Step 1. Download the starter folder

A ready folder with rules, four skills and two helper agents inside.

What you get: Everything in place before you type a word. No terminal, no settings.

  1. Click Download at the top of this page.
  2. Unzip it. You get a folder called My-Claude
  3. Move that folder to your Desktop.

Good to know: You need the Claude desktop app and a paid Claude plan. Get the app at claude.com/download.

Step 2. Open the folder in the Code tab

Claude Code lives inside the same Claude app. It is the tab called Code.

What you get: Claude working directly in your folder.

  1. Open the Claude app and click the Code tab.
  2. Click + New in the sidebar.
  3. Under the message box, click the project folder control and choose My-Claude on your Desktop.
  4. Set the permission mode to Manual. Claude then asks before it changes anything.

Good to know: When you are comfortable, Accept edits lets Claude change files without asking each time. Leave Bypass permissions alone.

Step 3. Say three words

No long prompt to paste. The folder already tells Claude what to do.

What you get: Claude interviews you, one question at a time, and writes down who you are and how you work.

  1. Type the line below and press Enter.
  2. Answer the 7 questions. Short answers are fine.
  3. Say yes when Claude asks to save what it learned.
Type this
Set me up.

Good to know: Claude reads a file called CLAUDE.md in your folder at the start of every session. That is why it knows what to do.

Step 4. Look at what you have

From now on, every new session in this folder starts already knowing you.

What you get: A home for your work that Claude understands.

  1. CLAUDE.md is the rule book Claude reads first, every time.
  2. about-me.md is who you are. Open it and fix anything.
  3. 00_Inbox is where you drop files. 01_Projects has one folder per project.
  4. Four skills and two helper agents are already inside. Type / in the message box to see the skills.

Daily habits

New task? Type /clear

Yesterday's job is still in the chat. Claude rereads it with every message, and you pay for it.

What you get: A clean start. Better answers, and less of your limit used.

  1. When you move to an unrelated task, type /clear
  2. Your folder, your rules and your skills stay. Only the chat history goes.
Type this
/clear

Good to know: Anthropic's own advice: /clear between unrelated tasks costs nothing, and the next task does not keep paying for the last one.

Long job? Type /compact with a focus

You are deep in one long job and the chat is getting heavy, but you cannot start over.

What you get: Claude sums up the chat so far and keeps going with a lighter load.

  1. Type /compact and say what must be kept.
Type this
/compact keep the decisions we made and the file names

Good to know: Claude also does this by itself when a chat gets very long. Use /clear when the task is finished, and /compact when it is not.

Two failed fixes? Start over

You corrected Claude twice and it is still wrong. A third correction rarely helps.

What you get: One clean prompt that includes what you learned, in place of a chat full of failed tries.

  1. Type /clear
  2. Write one new prompt that says what you now know you want.

Good to know: This is from Anthropic's best practices: after two failed corrections, clear and write a better prompt.

Big job? Ask for the plan first

Claude ran for ten minutes and built the wrong thing.

What you get: You see the approach before any file is touched.

  1. In the mode selector under the message box, choose Plan.
  2. Describe the job. Claude looks around and proposes a plan without changing anything.
  3. Say yes, or say what to change. Then switch back to Manual.

Tell Claude how to check its work

Claude says it is done. It is not quite done.

What you get: A result that comes with proof.

  1. End your request with what done looks like, and how to check it.
Add this to a request
Before you say you are done: check every number against the source file, open the finished file to make sure it works, and tell me what you could not check.

Stop it the moment it drifts

You can see Claude heading the wrong way, and you wait politely for it to finish.

What you get: Seconds lost, not minutes.

  1. Press Esc to stop Claude at once. Then say what to do differently.
  2. To undo, type /rewind and pick an earlier point in the chat.

Teach it once, in CLAUDE.md

You correct the same thing every week.

What you get: A rule Claude reads at the start of every session.

  1. When you have corrected Claude twice on the same thing, paste the line below.
Paste this
Add this rule to CLAUDE.md so you remember it every time: WHAT CLAUDE SHOULD DO.

Good to know: Keep CLAUDE.md short. Anthropic recommends under 200 lines. A long rule book gets followed less.

Hand work to other agents

Send a job to a helper and get a report back

You want background research, but you do not want 40 web pages dumped into your main chat.

What you get: A helper does the digging in the background. Your chat gets only the answer.

  1. Ask for a subagent in plain words, and say how short the report should be.
  2. Carry on with your work. The helper reports back when it is done.
  3. To watch it, open Background tasks from the ⋮ menu in the title bar.
Paste this
Use the researcher subagent to find out WHAT YOU NEED TO KNOW. Report back in 10 lines with sources.

Good to know: A helper uses extra tokens, because it does its own reading. Use it for real digging, not for small questions.

Get a fresh pair of eyes on a draft

Claude wrote the draft, so Claude thinks the draft is good.

What you get: A review by a helper that never saw your conversation, so it is not swayed by it.

  1. When a draft is ready, paste the line below.
Paste this
Use the reviewer subagent on this draft. Give it the draft and my original request, nothing else. Show me its score and its top 3 fixes.

Good to know: The reviewer in your starter folder can only read files. It cannot change anything.

Run two jobs at the same time

One job is running and you are waiting. You have another job to start.

What you get: Two or more sessions working side by side, each with its own chat.

  1. Click + New in the sidebar to start a second session in the same folder.
  2. Each session has its own history. Switch between them in the sidebar.
  3. Hold Alt (Mac: Option) and click a session to open it beside the first.

Let one chat hand work to another, and report back

In the middle of a job you spot a second job. You do not want to lose your place.

What you get: The second job runs in its own session. Your main chat hears how it went.

  1. When Claude spots work outside your current task, it suggests a task. Click Start. It opens in a new session, listed under this one.
  2. Or ask for it yourself with the line below.
  3. Later, ask your main chat what the other session found.
Paste this
This is a separate job. Suggest it as its own task so it runs in another session: DESCRIBE THE JOB. When it is done, tell me what it found.

Good to know: Claude can read what your other sessions in the app have been doing, and send them messages. Ask it: what did the research session conclude?

Make your own helper

You keep giving a helper the same instructions.

What you get: A named helper you can call any time, with only the powers you give it.

  1. Paste the line below and describe the helper.
  2. Claude writes a small file in your folder under .claude/agents
  3. Give a helper that only checks things the read-only tools. Then it cannot change your files.
Paste this
Create a subagent called NAME. Its job: WHAT IT DOES. Give it only the tools it needs. If it only checks or reads, give it Read, Grep and Glob only. Show me the file before you save it.
